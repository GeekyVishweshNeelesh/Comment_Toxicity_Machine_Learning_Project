🧠 Toxic Comment Classification

This project focuses on detecting toxic comments using Machine Learning models. The dataset comes from the Jigsaw Toxic Comment Classification Challenge (Kaggle). The goal is to classify text comments into multiple categories of toxicity:

Toxic

Severe Toxic

Obscene

Threat

Insult

Identity Hate

A Streamlit web app has been built to allow users to input a comment and check whether it falls under any of these categories.






⚙️ Features

Multi-label classification of toxic comments.

Trained XGBoost model with TF-IDF vectorization.

Deployment-ready model files (.pkl).

Streamlit UI for real-time predictions.
